# 杭州光影历

杭州全年摄影地图网站：12 个月、18 个机位、3 条主题路线，包含取景位置、光线、构图、手机拍法和出行提示。

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。无需安装依赖。

```sh
npm test
npm run check
npm run build
```

`dist/` 为可交由静态服务器托管的产物。本次没有部署。

## 部署到 Vercel

已提供 `vercel.json`，Vercel 导入此项目后可直接采用以下设置：

- Root Directory：`hangzhou-photo-map`（如果上传的是本项目本身，则使用仓库根目录）。
- Framework Preset：Other。
- Build Command：`npm run build`。
- Output Directory：`dist`。
- Install Command：保持默认即可；本项目没有 npm 依赖。
- 无需环境变量或地图服务密钥。

也可以在本项目目录自行运行 `npx vercel`，根据提示关联自己的账号和项目。部署生产版本可自行运行 `npx vercel --prod`。

`.vercelignore` 排除测试、文档、本地浏览器验证产物及本地 `dist/`；Vercel 会从源码重新构建。`.vercel/` 已加入 Git 忽略，不会把本机项目关联信息提交到仓库。

支持月份与题材筛选、关键词搜索、地图列表联动、地图缩放与拖动、机位攻略弹窗、收藏持久化、路线批量收藏及清单导出。手机、平板和桌面均有响应式布局。

内容来源可在网页底部打开，研究记录见 `docs/research.md`。所有照片已保存本地；18个机位各绑定一张已核对地点的实景，图片清单见 `src/spot-photos.js`，并提供原图和图文出处。路线封面来自沿途机位。历史照片不代表实时花情。Google Fonts 为可选增强，网络不可用时回退到系统宋体；网站核心功能不依赖远程服务。高德导航和资料原文需要联网。

地图为自绘机位分布示意，非精确路网或导航。季节与花期为参考，出行应查询当年天气、花情及官方公告。

## 中英文国际化

顶部语言选择支持「中文 / EN」，覆盖月份、题材、地图、18 个机位攻略、3 条路线、摄影手记、提示和清单导出。英文界面保留中文地点名称，资料名称与作者署名保留原文，方便查找与核对。

语言优先级为 URL `?lang=en` / `?lang=zh-CN` → 浏览器已保存偏好 → 浏览器语言（英文使用英语，其余不支持语言回退中文）。切换语言保留当前月份、题材、搜索、收藏与地图状态，并更新可分享链接；本地存储不可用时仅在当前访问有效。搜索同时支持中英文关键词，高德始终使用中文地名。

翻译维护：`src/en-ui.js` 为界面文案，`src/en-content.js` 为机位、路线和月份内容，`src/i18n.js` 负责语言解析、渲染翻译与双语搜索。新增中文文案时补充对应英文；新增机位必须补齐六项英文内容并通过完整性测试。保持静态构建，无额外依赖，Vercel 设置无需调整。
